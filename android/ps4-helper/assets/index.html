Start the server

Tap the button to start the jailbreak page server on this phone (it runs in Termux). Keep the phone on the same Wi-Fi as the PS4.

Best network: a spare offline router. Factory-reset it, join its default Wi-Fi from the sticker, open the sticker address (often http://192.168.10.1), set a Wi-Fi name and password, skip the internet step. Join this phone and the PS4 to it. The PS4 internet test will fail; that's fine. Do not put this spare router on an existing home LAN (the default LAN IP can clash). Backup: use the phone hotspot.

If it doesn't start: tap the 'PS4 Servers' widget on your home screen instead.
