# Kush & Caps (WEED00001) v1.00
Top-down pixel dealer sim for jailbroken PS4 (OpenOrbis / GoldHEN).

## Controls
- Left stick / D-pad: walk
- Cross (X): talk / open prompt (dealer, buyer, grow beds, home)
- Circle / Cross in menu: confirm choice
- D-pad in menu: move cursor
- Options: quick save (also Home > Save)
- Triangle: smoke weed (effect)
- Square: eat mushrooms (effect)

## Features
Walk town, buy seeds/product from purple dealer, plant/harvest at grow beds, sell to buyers (daily wants), fluctuating prices, heat meter, police raids, smoke/eat visual effects (wobble, tint, slow-mo, trails), save/load.

## Install
Copy KushAndCaps.pkg to USB, on PS4: GoldHEN Package Installer, or FTP to /data/pkg and install.
Title ID WEED00001. Fake-signed via create-fself.
